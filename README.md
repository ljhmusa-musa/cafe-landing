# ☕ 모닝빈 카페 랜딩 페이지

가상의 카페 "모닝빈"을 소개하는 간단한 한 페이지짜리 랜딩 페이지입니다. 순수 HTML/CSS로만 만들어져 별도의 빌드나 설치 없이 바로 볼 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 스타일 및 모바일 반응형 레이아웃 |

## 사용 방법

`index.html` 파일을 브라우저에서 열면 됩니다.

## 참고

- 카페 이름, 메뉴 가격, 주소, 전화번호는 모두 예시 데이터입니다. 실제 정보로 수정해서 사용하세요.
